## 一致性要求

1. 頁面文案、示例資料、狀態名稱和按鈕文字與 PRD、HTML 原型逐條一致。
2. 頁面順序和跳轉關係與互動流程圖一致。
3. 同類元件使用統一尺寸、圓角、描邊、圖示和狀態樣式。
4. 文字、按鈕、輸入框和動態資料保持為可編輯 UI 元素，不烘焙進圖片。
5. 品牌 Logo、真實產品圖、人物照片和專屬插畫優先使用使用者提供的原始資產。
6. 複雜圖片缺失時使用明確佔位，並在交付說明中列出待補資產。
7. 所有明顯可互動元素都要提供預設、懸停、按下、禁用或選中狀態中實際需要的部分。

## 繪製與驗證

1. 先呼叫 `get_editor_state` 獲取當前畫布狀態。
2. 呼叫 `get_guidelines` 載入可用設計指南。
3. 使用 `set_variables` 建立全域性設計變數。
4. 使用 `batch_design` 分批建立畫板和元件，每批控制在工具允許的運算元量內。
5. 每完成一組頁面後呼叫 `get_screenshot`，與 HTML 原型和參考材料對照檢查。
6. 優先修正整體佈局和尺寸，再修正字型、間距、顏色、圖示和細節狀態。
7. 全部確認後呼叫 `export_nodes`，將 PNG 匯出到當前需求的 `原型截圖/` 目錄。
