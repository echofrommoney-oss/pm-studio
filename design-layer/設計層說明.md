# 設計層說明

這個專案的 `.claude/skills/` 裝了六組設計工具，接線規則寫在 `.agents/workflows/pm-design.md`。日常只要在工作台或 Claude Code 說話就好，不必記命令：

| 你說 | 會發生什麼 |
|---|---|
| 「設計方向」「這個產品要長什麼樣」「照 xxx 網站的感覺」 | 建立或修改 `PRODUCT.md`（產品事實）與 `DESIGN.md`（設計系統） |
| 「檢查原型」「評審設計」「不像 AI 做的嗎」 | hallmark 打分 → 必修項直接改 → 需要時 impeccable 深度評審 |
| 「字太亂」「間距不對」「太素」「太吵」「文案不清楚」 | impeccable 的分項修正，一次一項 |
| 「加動效」 | 用 GSAP 官方 skill 做，尊重減少動態設定 |
| 「高保真」 | 走 Pencil，pencilplaybook 的感知規則 + `DESIGN.md` 的 token |
| 「查一下 xxx 風格 / 配色 / 字型」 | ui-ux-pro-max 本機資料庫 |

## 兩份專案級檔案

- `PRODUCT.md`：這是什麼產品、給誰用、承諾什麼。一個專案寫一次。
- `DESIGN.md`：色彩、字型、間距、圓角、動效、元件慣例。所有原型與 Pencil 稿以它為準，會隨原型定稿回寫。

兩份都放專案根目錄，都用繁體中文。

## Chrome 擴充功能：從網站抽 DESIGN.md

`設計層/chrome-extension/` 是 design-md-chrome（MIT）。裝法：

1. Chrome 開 `chrome://extensions`，右上角打開「開發人員模式」。
2. 按「載入未封裝項目」，選 `chrome-extension/` 這個資料夾。
3. 之後在任何網站點工具列圖示 → 「Auto-extract」→「Generate DESIGN.md」→「Download」。
4. 把下載的 `DESIGN.md` 放到專案根目錄，然後對 Claude 說「用我抓的 DESIGN.md 當設計方向」，它會補上版面策略與主題選擇（擴充功能只抓 token，不含版面）。

抽取只拿公開的 CSS 值當參考起點，不是複製對方的設計；hallmark 也會拒絕像素級複製。

## 需要網路的地方

- impeccable 的 `context` / `detect` / `live` 第一次執行會從 GitHub 下載它的引擎（會驗 sha256）。離線時它會自動降級改讀 `PRODUCT.md` / `DESIGN.md`。
- hallmark、pencilplaybook、gsap、ui-ux-pro-max 完全離線。
